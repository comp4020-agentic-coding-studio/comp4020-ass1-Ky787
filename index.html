    Technical details

    Every instruction, block, edge and count on this page is read from the pre-generated dataset in web_data/. Nothing is disassembled, lowered to IR, or otherwise regenerated in the browser. Toolchain, seed and the build command are the fixed parameters of the experiment that produced the dataset; the command is assembled from the selected configuration, since the dataset holds the compiled objects rather than the shell history. Every other row is read from the selected variant's JSON.
